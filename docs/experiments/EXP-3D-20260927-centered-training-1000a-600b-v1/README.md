# 锚点中心体积训练：1000 步 A + 600 步 B

按用户指定预算完成，单次运行，从 seed=20260927 重新初始化；没有续接旧 130 步，也没有根据结果增加步数。训练数据、帧角色、几何、backbone、写入规则、优化器和学习率均沿用前次 centered-support 实验，只有 A/B 步数变更。

## 固定配置

三场景 ai_001_001、ai_002_001、ai_003_001，仅 Hypersim TRAIN；分辨率128×160，体积[-6,-4,-6]..[6,4,6]，8³网格、128候选、双视图支持门槛不变。A学习率1e-3，B学习率3e-4，Adam，梯度裁剪1，renderer64采样。context_a=0/1/2，context_b=0/3/4，stream=5/6，query=12/13/14/15。配置与预登记在 config.json、preregistration.json。

## 已完成的运行

训练计时（含三个检查点评价）111.93 秒，峰值 CUDA 分配 254.93 MiB。1000+600 步完整记录，有限损失/梯度检查通过；B 的 600/600 步 writer 梯度非零，各场景200步。A各场景334/333/333步。

三份 checkpoint 均通过严格加载、OFF 状态复现及 ALL 两步非零 fast/state 精确重放。A阶段writer不变、B阶段writer确实更新。仅评价原来的12个 TRAIN queries，共36条初始/A/B raw记录；没有开发集或测试集结果。

## 固定查询上的结果

以下为三个场景等权、相同 context_a 的 OFF 重建指标。AbsRel、MSE、RMSE越低越好，SSIM越高越好。

| 检查点 | 深度 AbsRel | RGB MSE | RGB SSIM | 深度 RMSE |
|---|---:|---:|---:|---:|
| 旧 100A+30B 最终 | 1.229194 | 0.082984 | 0.283925 | 1.629804 |
| 本轮 1000A 结束 | 0.286576 | 0.036372 | 0.290911 | 0.792942 |
| 本轮 1000A+600B 最终 | 0.331528 | 0.043952 | 0.275538 | 0.914911 |

| 场景 | 旧100A+30B AbsRel | 本轮1000A AbsRel | 本轮1000A+600B AbsRel |
|---|---:|---:|---:|
| ai_001_001 | 0.453027 | 0.271135 | 0.416402 |
| ai_002_001 | 0.562733 | 0.146529 | 0.136033 |
| ai_003_001 | 2.671824 | 0.442064 | 0.442149 |

增加训练后，最终平均深度误差和RGB MSE相比旧短训练下降，但SSIM并未提升，不能概括为所有质量指标改善。尤其本轮A结束后再执行B，OFF重建的平均AbsRel、MSE、SSIM和RMSE均回退。A与B训练状态构造不同（B有额外stream观测及写入）；此处没有相同观测下OFF/写入的配对比较，因此既不能把B训练的效果当作写入收益，也不能仅凭OFF回退断言写入无效。两阶段权重均保留，未事后替换预定终点。

ai003此前的零梯度问题没有复发，其200个B训练步均有非零writer梯度。但本轮仍在相同三个场景及训练标签上反复优化，只证明训练集拟合和工程链路，未证明独立泛化或方法机制。
