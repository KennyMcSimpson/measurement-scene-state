# EXP-3D-CAJU3D-FUSENET-REPL-V1：冻结的学习式读出在另一批场所上的复现

**结论：`REPLICATED`。** FUSENET-V1 的三个冻结的 FUSE_BASE 网络只在 SYSTEM + SYSTEM2 上训练过。把它们原样用到 CAJU-V1 的 58 个场所上：
- Core B 从 0.1176 降到 0.0979（−17%），+0.0197 [+0.0072, +0.0380]；
- 58 个场所中 48 个变好，判定 SUPPORTED。

## 设计（[PROTOCOL.md](PROTOCOL.md)，2026-10-14 22:34:28 锁定，见 `audit/locked_at.txt`）

- **场所**：CAJU_PILOT、CAJU_SEL、CAJU_EVAL，共 58 个 ARKit 训练折场所、232 个查询，与 FUSENET-V1 的训练、验证和确认场所都不重叠。
- **输入**：与 FUSENET-V1 相同的基础图像。来源是 CAJU-V1 的 100 步 TTT 回放和几何封存，每个文件核对哈希。
- **模型**：三个 BASE 网络按 FUSENET-V1 的 fit_log 核对哈希，读出取 log 平均；不跑 GPU，不重新训练。
- **H-JEPA 不参与**：这些场所在 H-JEPA 的训练集里，所以不评估 FUSE_JEPA。
- **完整性**：分析运行两次，逐字节一致。
