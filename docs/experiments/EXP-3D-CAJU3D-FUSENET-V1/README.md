# EXP-3D-CAJU3D-FUSENET-V1：CAJU-3D 第四步——学到的按像素读出：JEPA 的完整潜预测能否帮助"信谁"

**结论：`JEPA_FUSION_NOT_ESTABLISHED`；次要发现：学到的读出（不用 JEPA）大幅改善 Core B，几乎全部来自对未覆盖区域 R7 填充的修正。**

- **JEPA 部分不成立**：在相同结构的网络里加入 H-JEPA 的查询格预测（ẑ、log P、命中），没有改进学到的读出。
  - P1（SYSTEM3）：−0.00098，80/0/80；
  - P2（VAL）：+0.00186，34/0/46。
- **不用 JEPA 的学到的读出（FUSE_BASE）**：

  | 队列 | Core B → FUSE_BASE | 差值 [95% CI] | 场所 好/平/坏 | 判定 |
  |---|---|---|---|---|
  | SYSTEM3 | 0.1569 → 0.1143 | +0.0426 [+0.0204, +0.0739] | 119/0/41 | PARTIAL |
  | VAL | 0.1161 → 0.0984 | +0.0176 [+0.0093, +0.0270] | 63/0/17 | SUPPORTED |

  - 改善偏重尾：中位场所只改善 +0.006（SYSTEM3）和 +0.008（VAL），约四分之一的场所略变差。
  - 改善集中在 Core B 本来误差很大的场所（秩相关 0.56）。

## 设计（[PROTOCOL.md](PROTOCOL.md)，2026-10-14 22:20:46 锁定，sha256 `fda3cf90…`）

- **队列**：与 KFUSE-V1 相同，根目录文件逐字节复制。
  - 拟合集 SYSTEM + SYSTEM2，按种子划分为 128 个训练场所和 32 个验证场所；
  - 确认集 SYSTEM3（160 个场所）和 VAL（80 个场所）。
- **输入**（只来自到达数据和查询相机）：
  - 基础图像 8 通道：log R7、log F7、分歧、α、near7、cosine、是否已覆盖、log TTT 原始深度；
  - JEPA 臂另加 66 通道：第二步冻结的 H-JEPA 在查询格上的 ẑ、log P、命中。
- **FuseNet**：
  - 5 层膨胀卷积，32 通道；
  - 已覆盖像素输出卡尔曼式权重 w，结果为 R7^(1−w)·F7^w；
  - 未覆盖像素输出有界修正 r = 0.7·tanh(·)，结果为 R7·e^r；
  - 输出头初始化为零，未训练时等于 Core B。
- **训练**：
  - 每个臂 3 个种子，30 个 epoch，Adam lr 1e-3，损失为场所加权的 AbsRel；
  - 每个种子取验证集上最好的 epoch；读出取三个种子的平均；
  - 6 个网络在 GPU 4 上共用 136 秒。
  - 模型哈希记录之后，才读取确认集真值。
- **完整性**：
  - 8 个测试通过；
  - 特征排练与第三步的 log P 完全一致；
  - 确认在 CPU 上运行两次，逐字节一致。

## 解读

- **JEPA 在第四个角色里也没有作用**：
  - 前面已检验过三个角色：挑 TTT 的测量、读出的方差 P、何时更新（Gate 0）。
  - 本实验给出 H-JEPA 预测的完整潜特征，学到的读出也没有因此变好。
- **最大的可改进之处在未覆盖区域**：
  - R7 在那里用最近邻或调和插值加常数填充，误差很大（远处 AbsRel 0.49）。
  - 一个只看到达数据的小网络，就能消掉约三分之一。
  - 这与以前补全线的结论一致：平均改善大、逐场所不稳。
  - 不同的是，这里在同域、用与部署时相同的输入训练，系统级均值改善显著。
- **在已覆盖像素上**，学到的权重不如冻结的分箱表（−0.0006），说明那里的信息已被分箱表用尽。
- **下一步**：
  - 冻结的 FUSE_BASE 已在 CAJU-V1 的 58 个场所上预注册复现：0.1176 → 0.0979，48/0/10，REPLICATED（EXP-3D-CAJU3D-FUSENET-REPL-V1）。
  - 若要实际采用，需要专门改进逐场所的一致性，例如用分箱表处理已覆盖像素、只学未覆盖修正，并在全新队列上确认。
