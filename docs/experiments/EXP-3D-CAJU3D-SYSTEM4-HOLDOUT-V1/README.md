**结论：`LEARNED_READOUT_PARTIAL`。** 在 52 个今晚之前从未准备、从未评测过的 ARKit 场所上：
- **两个学到的读出都大幅改善 Core B**：
  - V2（按计划新训练）：0.1462 → 0.0923，47/0/5；
  - V1（冻结）：0.1462 → 0.0960，46/0/6。
  - 均值的置信区间都不含 0，去掉任一场所后的估计全部为正。
- **为什么是 PARTIAL 而不是 SUPPORTED**：改善最多的一个场所贡献了超过一半的正向收益（52% 和 56%），没有通过 V2 判定的"头部占比 ≤ 0.5"检查。
- **卡尔曼式分箱表**：在第四批全新场所上再次复现，SUPPORTED。

## 解读

- **学到的读出在全新数据上成立，而且比以前的队列更一致**：
  - 90% 的场所变好，中位改善 +0.014，去掉任一场所后均值仍至少 +0.022。
  - 只差在收益的头部集中度这一项检查上。
- **V2 的配方更好**：已覆盖像素交给冻结的分箱表、更大的感受野、更多训练数据（458 个场所）。它在每一项上都略好于 V1，变差的场所从 6 个降到 5 个。
- **卡尔曼式分箱表在四批场所上都成立**，约 2–2.5%。
- **综合四批场所**：Core B 最大的弱点是未覆盖区域的填充。一个只用到达数据和查询相机、同域训练的小网络，就能把那里的误差降低约 20–40%（SYSTEM4 上为 42%）。
