# 修正案 2（事后补充）：候选 B 的前提检验（神谕上界）

**性质**：

- 本修正案在看到 Phase 1–2 结果之后、修正案 1 结果出来之前撰写，属于探索性分析。
- 它不训练任何模型，只用 Phase 1 保存的 B7（V2 配方）预测，在 CPU 上计算。
- 不改变 Gate A、Gate B 或修正案 1 的任何判定。
- 运行前锁定：文档和代码的哈希写入 `AMENDMENT_2.lock.json`。

## 要回答的问题

候选 B 设想把逐查询的深度修正，换成一个各查询视角共享、三维一致的修正状态。它能提高精度的前提是：

- 两个查询视角看到同一块未覆盖表面时，各自的修正误差不完全相关；
- 因此把两个视角对同一表面点的估计合起来，能降低误差。

如果连"已知真实对应关系"的理想合并都改善不大，任何可部署的共享修正也不可能在精度上超过 V2。这时候选 B 只能以一致性为卖点，不能以精度为卖点。

## 方法

- **数据**：
  - 4 个评价折，共 350 个场所、700 个情节，每个情节两个查询视角；
  - B7 的保存预测（float16），协议定义的未覆盖区域（TTT α < 0.5）。
- **神谕对应**：
  1. 把源视角的真值表面点（有效像素）投影到目标视角，用 1 像素 z-buffer 保留最近的点。
  2. 目标像素同时满足以下条件时，与源像素构成对应：
     - 目标像素未覆盖；
     - 目标像素真值有效；
     - 投影距离与目标真值的对数差小于 0.02，即同一可见表面。
  3. 两个方向都计算。
  - 真值只用来确定对应关系和评分，可部署的方法拿不到它，所以结果是**上界**。
- **在每个对应像素上比较**：
  - B7_F16：目标视角自己的 B7 预测；
  - SHARED：目标预测与"沿真实对应搬运过来的源预测"的几何平均，即用两个视角对同一表面点的估计构成一个共享估计；
  - BEST：两者中较好的一个。这是更宽松的超神谕，只作描述。
- **汇总**：
  - 每个目标查询把对应像素替换后，重新计算全部有效像素的 AbsRel；
  - 场所取情节平均的查询平均；
  - 用 V1 的配对场所 bootstrap（10,000 次，种子 20260928）。

## 判定（运行前锁定）

- **主比较：B7_F16 − SHARED**，合并 350 个场所。
  - 均值 ≥ 0.005 且 CI 下界 > 0 时，标为 `B_PREMISE_ACCURACY=SUPPORTED`；否则标为 `NOT_SUPPORTED`。
  - 0.005 与 Gate A 的实际意义门槛相同。
  - 这是理想对应下的上界：如果上界都达不到 0.005，候选 B 在精度上不值得开发。
- **描述性**：
  - 对应像素占未覆盖有效像素的比例；
  - 源像素中已覆盖的比例；
  - 两个视角对数误差的相关系数；
  - B7 两个视角之间不一致程度的分布；
  - 各折结果；
  - BEST 上界。

## 完整性

- 只读保存的预测、缓存、查询真值（`SEALED_QUERY_EVALUATION`）和查询相机（`QUERY_CAMERA_TEACHER_ONLY`），不使用 GPU，不下载数据。
- 锁定前在冒烟折 FIT_SYSTEM2（训练队列，1 个 epoch 的 B7）上运行过一次，只检查代码。
