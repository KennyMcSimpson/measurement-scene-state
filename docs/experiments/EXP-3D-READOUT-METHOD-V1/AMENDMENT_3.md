# 修正案 3（事后补充）：候选 A 的前提检验（自由空间下界）

**性质**：

- 本修正案在看到修正案 2 的结果之后、修正案 1 的结果出来之前撰写，属于探索性分析。
- 它不训练任何模型，只把一个可部署、无学习的几何约束施加在 Phase 1 保存的预测上，在 CPU 上计算。
- 不改变 Gate A、Gate B、修正案 1、修正案 2 的任何判定。
- 运行前锁定：文档和代码的哈希写入 `AMENDMENT_3.lock.json`。

## 要回答的问题

候选 A 主张：显式建模每个查询像素的测量支持，把"真实测量"与"模型外推"分开，可以得到更可靠的深度。它在几何上最直接、可证伪的形式是自由空间约束：

- 到达帧看到某个表面时，相机与该表面之间的空间是空的；
- 静态场景的真实表面不会落在这些空的空间里。

因此，每条查询射线都有一个自由空间下界。V2 等读出在未覆盖区域做的是外推，如果外推经常把表面放进已观测为空的空间，用这个下界截断就能降低误差。

如果截断带来的改善很小，说明"测量支持"中最硬的几何信息已经被现有读出隐含利用，候选 A 的增量空间不足。

## 方法

- **自由空间判定**：
  - 点 X 满足下式时，判为自由空间：
    - 存在某个到达帧 j，X 落在其图像内且该像素测量有效；
    - |X − c_j| < D_j(π_j(X))·(1 − 0.05) − 0.05 m。
  - 其中 D_j 是测量的射线距离。
- **查询射线的下界**：
  - 在 0.1–20 m 之间按对数等距取 128 个采样点。
  - 从近到远连续被判为自由空间的前缀中，最后一个采样点的距离为下界 t_lb。
  - 第一个采样点就不是自由空间时，t_lb = 0，即不施加约束。
- **可部署读出 X_FS**：在协议的未覆盖像素（TTT α < 0.5）上，取 max(X, t_lb)；其余像素不变。
  - 只用 7 个到达帧和查询相机，不用任何真值。
- **作用对象**：B7（V2 配方）、B5（最强简单校准）、R7，均为保存的 float16 预测。
- **评分**：
  - 场所取情节平均的查询平均；
  - 用 V1 的配对场所 bootstrap（10,000 次，种子 20260928），合并 350 个场所。

## 判定（运行前锁定）

- **主比较：B7 − B7_FS**。
  - 均值 ≥ 0.005 且 CI 下界 > 0 时，标为 `A_PREMISE_FREE_SPACE=SUPPORTED`；否则标为 `NOT_SUPPORTED`。
  - 0.005 与 Gate A 的门槛相同。
- **描述性**：
  - B5 − B5_FS、R7 − R7_FS；
  - 下界起作用的像素比例；
  - 预测或真值落在自由空间内的比例（真值落入的比例即划分错误率）；
  - 各区域像素误差、各折结果。

## 完整性

- 读取范围：到达帧测量（与 R7 构建相同的读取，用途 `ORACLE_TEACHER_ONLY`）、查询相机（`QUERY_CAMERA_TEACHER_ONLY`）、查询真值（`SEALED_QUERY_EVALUATION`，只用于评分）。
- 不使用 GPU，不下载数据。
- 锁定前在冒烟折 FIT_SYSTEM2（训练队列）上运行过一次，只检查代码。
- 参数（0.05、0.05 m、128 个采样点、0.1–20 m）在运行前固定，不做调整。
