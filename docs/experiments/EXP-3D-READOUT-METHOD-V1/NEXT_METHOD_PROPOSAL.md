  - 第一步只需 CPU，0 GPU 小时；如果连这一步都不通过，就结束。

**由此得到的判断**

- 一半以上的剩余误差在没有任何到达帧观测到的区域。
- 在同样的输入上做几何推理，空间都很小：
  - 跨视角共享，两个视角的对数误差相关系数为 0.78，它们犯的是同一个错；
  - 自由空间约束，V2 只有 1.5% 的未覆盖像素违反下界，而 R7 为 7.1%；
  - 换一种融合规则。
- 真正起作用的是**学习到的先验**（空间上下文、DepthSplat 特征），以及 TTT 在**有测量处**的贴合。
- 瓶颈是信息，不是读出机制。

## 推荐方向：证据分型可靠读出（ETR）

### 数学定义

对查询像素 u 及其射线 r_u(t) = o + t·d_u，只用 7 个到达帧和查询相机：

- **测量命中**：H(u) = 到达帧中重投影到 u（1 像素内）的测量点集合；有命中时 m(u) 为最近的射线距离（即 R7 的命中值）。
- **自由空间**：F(u) = { t : 存在到达帧 j，使 |r_u(t) − c_j| < D_j(π_j(r_u(t)))·(1 − ρ) − δ }，取 ρ = 0.05、δ = 0.05 m。
- **下界**：t_lb(u) = 从近端开始、连续落在 F(u) 中的前缀的终点；没有这样的前缀时为 0。
- **证据类型**：
  - H(u) 非空时，e(u) = MEASURED；
  - 否则 t_lb(u) > 0 时，e(u) = CARVED；
  - 其余为 UNSEEN。
- **读出**：
  - 点估计：log d̂(u) = log max(t_lb(u), b(u)) + Δ_θ(x_u)。其中 b 为 B7 的读出，Δ_θ 为有界修正。
  - 尺度：σ_θ(u) > 0。
- **训练**：在对数深度上用拉普拉斯负对数似然，权重为场所加权：
  - L = Σ_u w_u · [ |log d̂(u) − log d*(u)| / σ_θ(u) + log σ_θ(u) ]。
- **校准**：
  - 对每种证据类型 e，在训练场所上取分位数 q_e，使 |log d̂ − log d*| / σ_θ ≤ q_e 的比例为 1 − α，即按类型做 split conformal。
  - 输出区间为 [max(t_lb, d̂·e^(−q_e σ_θ)), d̂·e^(q_e σ_θ)]。在场所可交换的假设下，每种证据类型都有边际覆盖保证。

### 独立创新点（必须同时成立，否则不成立）

1. 不确定性直接以"测量命中 / 自由空间 / 完全未见"三种证据类型为条件。这不同于只把置信度作为输入通道（DoubleTake），也不同于只数可见次数（GAVIS）。
2. 区间的下端受自由空间约束，永远不覆盖已观测为空的空间。
3. 场景是无图像查询视角上的流式 RGB-D。

坦白说：每一块都已有先例。三态来自 Curless & Levoy 1996，自由空间来自 Merrell 2007，此外还有共形预测、异方差回归。新意只在组合与任务设定上，单独不足以支撑 CVPR 主会。

### 失败条件（任一成立即停止）

- **F1（已部分触发）**：自由空间下界对精度的增益 < 0.005。修正案 3 的结果为 +0.0003，因此 ETR 不能以精度为卖点。
- **F2**：不训练新模型、只对 B7 残差按区域做 split conformal（第 0 步）时，覆盖率、平均区间宽度和 AUSE 与 ETR 相差都在 5% 以内。这说明没有方法贡献。
- **F3**：ETR 的场所平均 AbsRel 比 B7 差 0.002 以上。
- **F4**：留出折上任一证据类型的实际覆盖率偏离名义值 5 个百分点以上。

### 强基线

- B7 + 全局 split conformal；B7 + 按区域（覆盖、近命中、填充）split conformal；
- B7 三个种子的离散度，作为集成不确定性；MC dropout；
- 64 箱表残差分位数；
- DoubleTake 式"提示 + 置信度"；GAVIS 式可见性计数；Eldesokey 2020 式置信度传播。

### 最小可证伪实验

- **第 0 步**：CPU，约 1 小时，不训练。
  - 用保存的 B7 预测做留一队列 split conformal：用其余三折校准，在留出折评价。
  - 报告每种证据类型的覆盖率、区间宽度、AUSE 和风险–覆盖曲线。
  - 这一步给出 ETR 必须超过的基线；判定规则在第 1 步之前锁定。
- **第 1 步**：GPU 4，约 2 GPU 小时。
  - 在 B7 主干上加 σ_θ 头，3 个种子 × 4 折，与第 0 步比较 F2–F4。
- 第 1 步通过后，才需要考虑全新数据确认与第二个数据源。

### 计算投入

- 第 0 步：0 GPU 小时。
- 第 1 步：约 2 GPU 小时。
- 含消融：约 6 GPU 小时。
- 只用现有缓存与预测，不需要下载数据。

## 没有推荐的方向

- **候选 B（跨视角一致的共享修正）**：
  - 理想对应下的精度上界只有 +0.0008，逐像素挑选较好视角的超神谕也只有 +0.0041，都低于 0.005。
  - 两个视角的误差高度相关（0.78）。
  - B7 两视角的不一致确实存在（对数差的中位数约 0.05），所以 B 只剩"一致性"这个卖点；除非一致性本身就是目标，否则不值得开发。
- **候选 C（相关误差的可靠度融合）**：
  - 只有一种传感器，跨传感器的核心主张无法检验。
  - 同一视角内的融合就是 64 箱表（+0.0030）；跨视角挑选的超神谕上界为 +0.0041。
- **更多 TTT、JEPA**：任务书不允许在没有新证据时重新引入。修正案 1 表明，TTT 的价值只在已覆盖像素上，而且代价是 45 倍耗时。
