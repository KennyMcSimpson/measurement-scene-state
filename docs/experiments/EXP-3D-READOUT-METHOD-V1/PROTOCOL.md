# EXP-3D-READOUT-METHOD-V1 协议（Phase 1：V2 能否被简单校准解释；Phase 2：强读出下 TTT 是否必要）

## 0. 数据与独立性（Phase 0 审计结论，详见 DATA_EXPOSURE_REGISTRY.md）

- **队列**：六个有 Core B 预测的 ARKitScenes 队列，互不共享场所，共 510 个场所、2040 个查询：
  - FIT_SYSTEM（80）、FIT_SYSTEM2（80）：拟合过 KF 表，在本实验中只作训练；
  - CONF_SYSTEM3（160）；
  - CONF_VAL（80）；
  - CAJU（58）；
  - ARKIT_SYSTEM4（52）。
- **全部是开发数据**：这些队列都已在以前的研究决策中使用过，没有一个是全新的确认集。本实验的结论是开发级证据，不作为独立泛化的声明。
- **保留的未用数据**：61 个已下载、从未准备的扫描（CONFIRM 13、SELECT 18、SYSTEM 5、SYSTEM2 25）。本实验不使用它们，留作日后冻结方法之后的确认。
- **输入**：都来自封存的预测，即到达帧和查询相机：
  - R7、near7、cosine；
  - 发布版 DepthSplat 的前馈渲染；
  - 100 步 TTT 渲染。
  - 查询真值只作训练目标和评分。

## 1. 设计（锁定）

- **留一队列**：依次把 CONF_SYSTEM3、CONF_VAL、CAJU、ARKIT_SYSTEM4 作为评价折。每折用其余全部队列训练，其中 10% 的训练场所（种子 20261500 + 折序号）用于网络选 epoch。主分析把 4 折合并，共 350 个场所。
- **Phase 1 的方法**：B1–B7 在已覆盖像素（TTT α ≥ 0.5）上都使用冻结的 KF 表（sha256 `15100550…`），只在未覆盖像素上不同。所有拟合只用训练场所，目标都是场所加权的 AbsRel。
  - B0：Core B；
  - B1：Core B + 64 箱表；
  - B2A：零命中查询（整张 R7 都是 Hypersim 常数 2.37 m）改用训练集标定的常数；
  - B2B：B2A，再为未覆盖的 near7 像素和填充像素各配一个缩放；
  - B3：B2A，再对其余未覆盖像素做对数仿射 a + b·log R7；
  - B4：12 个低维几何特征的线性修正；
  - B5：288 箱的分箱修正：R7 与 TTT 深度的混合权重加偏移；
  - B6：逐像素 MLP 8-32-32-1，使用 V2 的 8 个输入；
  - B6W：逐像素 MLP 8-150-150-150-1，参数量与 V2 相当，同样没有空间上下文；
  - B7：V2 的配方（膨胀 CNN），每折重训。
  - B6、B6W、B7 各 3 个种子，30 个 epoch，Adam lr 1e-3，权重衰减 1e-4，每批 8 个查询，读出取 log 平均。
- **Phase 2 的方法**：三个系统使用同一种读出：log 预测 = log R7 + tanh(网络)，覆盖所有像素，网络为 V2 的主干。训练与 B7 相同，每个系统 3 个种子。
  - SYS_A：只有 10 个几何通道（log R7、near7、cosine、填充距离、零命中标记、near7 处 log R7 的三个分位数、像素行列）；
  - SYS_B：几何通道 + 前馈渲染的 4 个通道；
  - SYS_C：几何通道 + TTT 渲染的 4 个通道，通道数与 SYS_B 相同。
  - 交换检验：SYS_C 的网络用 SYS_B 的输入，SYS_B 的网络用 SYS_C 的输入。
  - 非学习参照：R7、Core A（前馈）、Core B（TTT）。
- **区域**（固定）：
  - COV：TTT α ≥ 0.5；
  - UNC_NEAR：未覆盖、R7 距命中 8 像素内；
  - UNC_FILL：未覆盖、R7 为填充；
  - 仅用于评价的分层：零命中查询、填充距离（0–8、8–32、>32 像素）、深度边缘与远处（> 4 m）。后两者由真值定义，从不作为输入。

## 2. 判定（锁定，查看任何评价折结果之前）

- **Gate A（V2_METHOD_NECESSITY）**：设 S* 为 B2A、B2B、B3、B4、B5 中合并 350 个场所均值最低者（在评价数据上取最强，对 V2 是保守的）。以下全部满足为 SUPPORTED，否则 NOT_ESTABLISHED：
  - (a) B7 对 S* 的配对场所 bootstrap 95% CI 下界 > 0（V1 方法，10,000 次，种子 20260928）；
  - (b) 均值改善 ≥ 0.005 AbsRel。这一门槛约为 Core B 误差的 5%、KF 表收益的 1.5 倍；
  - (c) 最大单个场所的正向贡献 ≤ 0.5；
  - (d) 中位场所改善 > 0；
  - (e) 在 4 个折中的每一个，B7 在未覆盖像素（UNC_NEAR + UNC_FILL）上的像素 AbsRel 都低于 S*。
- **Gate B（TTT_ADDED_VALUE）**：SYS_C 对 SYS_B（合并 350 个场所）满足以下全部为 SUPPORTED，否则 NOT_ESTABLISHED：
  - CI 下界 > 0；
  - 均值改善 ≥ 0.002（约为读出后误差的 2%）；
  - 中位场所改善 > 0；
  - 最大单个场所的正向贡献 ≤ 0.5。
- **次要（描述性）**：
  - B7 对 B6W（空间上下文是否必要）；
  - SYS_B 对 SYS_A（前馈 DepthSplat 的价值）；
  - 交换检验；
  - 各区域与分层的收益贡献、最坏 10% 场所、去掉任一场所的范围、逐折结果。
- **披露**：锁定前做过一次代码冒烟运行：用 FIT_SYSTEM 训练、在 FIT_SYSTEM2（训练队列）上评分，网络 1 个种子、1 个 epoch。它显示零命中查询的常数填充误差很大（AbsRel 约 4.9）。门槛按误差尺度和计算成本设定，不依据冒烟结果；评价折的结果在锁定前都没有看过。

## 3. 完整性

- 所有输入都来自核对过哈希的封存；真值只经 TeacherAccess 读取。
- 评分在 CPU 上用同一组保存的预测计算两次，结果必须逐字节一致。
- 只用 GPU 4；不下载数据；不打开受保护的保留集；预测与权重不进 git。
