2026-09-29 16:22–16:44 运行。只在 TRAIN24 上训练，在其余 48 个 TRAIN 场景（TRAIN-X，本试验未用于训练）上评价。试验自己的宽先验只用 TRAIN24 的帧拟合，所以 TRAIN-X 的深度从不参与确定 bounds。不读取 DEV、FRESH 或 final holdout。

## 解读

- 更宽的盒子修好了远处被截断的表面（5.67–10 m：0.60 → 0.43），训练集拟合也更好。
- 但 RGB-only carrier 无法从 RGB 定位深度；盒子变大后，近处表面被整体推远（0–2 m 高估 +1.92），而 0–4 m 占一半像素，AbsRel 对近处高估的惩罚又没有上限，所以总误差变大。
- 结论：RGB-only 的失败主要不是 bounds 截断造成的，瓶颈在几何证据本身；冻结盒子的截断反而限制了高估。
- 对 V10 的影响：V10 的预注册检验仍可运行，但它很可能落在分支 C。V10 排在 Core B V2 之后；这一调整只改变先后，不改变任何冻结的计划文件。
