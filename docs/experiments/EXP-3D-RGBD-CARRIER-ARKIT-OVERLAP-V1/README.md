# EXP-3D-RGBD-CARRIER-ARKIT-OVERLAP-V1：用 ARKit 真实数据做重叠感知训练的旧基座补全载体

**结论：REAL_CARRIER_PARTIAL，REAL_DATA_CARRIER_NOT_ESTABLISHED。**

- **C1，PARTIAL：**
    - 旧基座的补全载体（G1 架构，约 6.4 万参数）改用 ARKit 训练折、只用有重叠的训练目标重新训练，得到 GA。
    - 在有重叠的新查询（第 6、7 帧）上，GA 平均明显好于调和插值：FARH AbsRel 从 0.452 降到 0.330（约 −27%），+0.1215 [+0.0676, +0.1806]。

- **C2，NOT_ESTABLISHED：** 与 Hypersim 训练的 G1 相比，ARKit 训练没有带来可确认的改进：0.330 对 0.344，+0.0138 [−0.0049, +0.0317]，80/0/67。
- **与调和插值取平均（HGAN）是本轮最一致的组合：** 100/0/47，即 68% 的场景变好，中位数 +0.031。它仍是 PARTIAL，没到 75%。
- **与 OVERLAP-V1 合起来看：**
    - 同样的查询上，四种学到的补全给出几乎相同的平均误差：Hypersim 训练的 G1N 0.344、ARKit 训练的 GA 0.330，DepthSplat 逆向 JEPA 的 JA 0.337 和 JO 0.341。
    - 一致性也几乎相同，都在 50–55% 的场景变好。
    - 模型类型、训练数据和训练目标的选择，对这个结果影响都很小。

## 解读

- **真实数据训练让载体更"敢"预测，但几乎没有更准。**
    - GA 的弃权比例从 20% 降到 13%，NEAR 上明显更好（0.109 对 0.183）。
    - 但在 FARH 上只比 Hypersim 训练的 G1 略好，且不显著。
- **"平均有效、逐场景不稳"是这类补全在真实数据上的共同特征，不取决于模型。**
    - 小载体和 DepthSplat、合成数据和真实数据、均匀目标和重叠目标，结果都一样：平均误差降约 1/4，但只有一半多的场景变好。
    - OVERLAP-V1 的事后探索还表明，按像素做一致性门控也不能改变这一点。
- **最稳妥的用法是与调和插值取平均。** HGAN 让 68% 的场景变好、中位数 +0.031，是目前在真实数据上最接近一致的补全方案。
    - 下一步可以在全新扫描上预注册检验它。
    - 也可以研究场景级的选择：判断哪些场景该用学到的补全，哪些该用调和插值。
