## 解读

- **学到的补全在真实数据上有一个小而一致的增益：** 用正确的归一化读出，再与调和插值平均，85% 的场景不变差，FAR 误差降低约 9%。这在全新的真实扫描上得到确认。
- **对照揭示的更大问题在调和插值本身：**
    - 在 ARKit 上，调和插值严重偏远，FAR AbsRel 为 0.75。仅仅把它减半，均值就能降到 0.49，但这不稳定（42/37），只说明它的尺度有系统偏差。
    - 一个可能的原因是调和补洞在无支撑边界使用的常数 2.37 m 来自 Hypersim 训练集，对 ARKit 的近距离室内场景偏远。这一点没有在本实验中检验。
- **未归一化读出的表面大增益（HG +0.369）再次出现：** 和 ARKIT_VAL 上一样，它是两种相反偏差的抵消，不能作为补全有效的证据。
