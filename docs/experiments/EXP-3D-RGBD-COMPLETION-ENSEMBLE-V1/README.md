## 解读

- **收缩换一致性：** 单独用 G1 的平均提升最大（+0.148），但只有 52/80 个场景变好。与调和插值等权平均后，平均提升几乎不变（S7：−0.015，不显著），一致性从 65% 升到 81%。原因是学到的补全出错时往往错得很远，与调和插值平均正好压住这些坏情况。这是经典的模型平均效应，不需要任何学习或调参。
- **逆向 JEPA 在这里没有贡献：** J 在 EVAL34 上单独只比调和插值好 0.033（41/39），远弱于它在 FRESH78 上的表现（+0.069）。加入集成也没有帮助。
- **对项目的含义：** 学到的补全在 FAR 上确实有价值，但要以"与测量驱动的插值取平均"的方式使用。新基座上的逆向 JEPA 并没有带来比旧小载体 G1 更好的补全。
