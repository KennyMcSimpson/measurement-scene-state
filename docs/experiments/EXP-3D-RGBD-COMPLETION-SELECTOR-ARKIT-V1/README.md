# EXP-3D-RGBD-COMPLETION-SELECTOR-ARKIT-V1：用上下文深度范围决定何时使用学到的补全

**结论：SELECTOR_CONSISTENT。**

- **主检验通过（P1）。**
    - 在 80 个全新的 ARKit 真实扫描上，规则是：上下文深度范围 S ≥ 1.2 时用 ARKit 训练的补全载体（GA），否则用调和插值。
    - 这条规则稳定胜过调和插值：FARH AbsRel 从 0.523 降到 0.411，差值 +0.1115 [+0.0600, +0.1675]，好/平/差 32/31/9。
    - 88% 的场景不变差，逐一剔除场景后的均值都为正，单个场景的最大正贡献占比 0.11，V2 gate 全部通过。
- **这是这条研究线上第一个预注册、样本外、在真实数据上通过 V2 gate 的补全结果。**
- **规则对三种模型都成立：**
    - Hypersim 训练的小载体 G1：+0.114，31/31/10，SUPPORTED；
    - ARKit 训练的 DepthSplat 逆向 JEPA（JO）：+0.073，29/31/12，SUPPORTED。
- **不做选择时，三种模型都只是 PARTIAL。** 例如 GA 为 +0.101，但只有 42/72 个场景变好。选择几乎不损失平均增益：GA − SEL_GAN = +0.0105，不显著。
- **机制很清楚：**
    - 上下文深度变化大的查询（118 个）：调和插值误差 0.694，GA 0.447，GA 在 81% 的查询上更好。
    - 深度变化小的查询（100 个）：调和插值本来就准（0.292），GA 反而略差（0.305），只在 39% 的查询上更好。
    - 场景层面，深度范围与 GA 增益的 Spearman 相关为 +0.57，与样本内的 +0.42 到 +0.56 一致。

## 解读

- **学到的补全在真实数据上的"不一致"是可预测的。**
    - 调和插值在深度层次丰富的场景里失败，学到的补全在那里大幅改善；在近似平面的场景里，调和插值已经很好，学到的补全只会添乱。
    - 上下文深度范围（三个上下文帧测得深度的 (p90 − p10) / 中位数）不需要任何真值，就能把这两类场景分开。
- **这条规则与模型无关。** 对 ARKit 训练的小载体、Hypersim 训练的小载体和 DepthSplat 逆向 JEPA 都有效。所以它反映的是场景几何的性质，而不是某个模型的特点。
- **实用意义：** 在真实 RGB-D 序列上补全未观测区域，可以用"深度范围 ≥ 1.2 时用学到的补全，否则用调和插值"。在本队列上，平均误差降低约 21%，而且 88% 的场景不变差。
- **局限：**
    - 只有 80 个扫描（72 个有 FARH）。
    - 只检验了近处视角（第 6、7 帧）。
    - 阈值来自一次样本内探索，没有优化过，换一个数据集可能需要重新标定。

## 事后探索：Hypersim 上的同一规则（探索性）

`exploratory_posthoc/hypersim_selector_check.*` 在 Hypersim 的 EVAL34 与 FRESH78 上，对 Hypersim 训练的小载体 G1（归一化读出）检查同一条规则。这两个队列已被反复使用，只作参考。

| 队列 | S 与增益的 Spearman | H3 − G1N | H3 − SEL（S ≥ 1.2） |
| --- | ---: | --- | --- |
| EVAL34 | −0.04 | +0.155，56/0/24 | +0.047，19/51/10（88% 不变差） |
| FRESH78 | +0.21 | +0.127，54/0/23 | +0.065，31/40/6（92% 不变差） |

- **在合成数据上，深度范围几乎不能预测增益。** 学到的补全在大多数场景都有帮助（约 70%），所以选择虽然也让结果一致，但会丢掉一半以上的平均增益。
- **在真实数据（ARKit）上，这个信号很强。** 深度变化小的场景里，调和插值已经很准（0.29），学到的补全没有用处，所以选择几乎不损失增益。
- **这条规则的价值取决于数据，不能当作普适的几何规律。** 它适用于真实 RGB-D 扫描。换到新的数据集，应该先检查 S 与增益的关系。
