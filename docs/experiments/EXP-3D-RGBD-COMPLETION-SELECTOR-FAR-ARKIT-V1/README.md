**结论：FAR_SELECTOR_CONSISTENT。**

    - DepthSplat 逆向 JEPA 不成立：JO +0.022、JA +0.042，95% CI 都包含 0。

- **增益比近处视角小，机制相同：**
    - 误差降低约 13%，近处视角是 21%；主检验也是勉强通过，CI 下界为 +0.006，不变差比例 77%。

    - 未选中的查询（66 个）：0.322 对 0.351，GA 只在 30% 的查询上更好。

## 解读

- **选择规则在真实数据上是稳健的。**
    - 近处视角（SELECTOR-V1）和远处视角（本实验）都通过了 V2 gate。
    - 在两种视角上，选择后的结果都比不选择更好、更一致。
- **规则的作用是识别"调和插值会失败的场景"。**
    - 远处视角上，学到的补全整体只与调和插值打平；但在深度层次丰富的场景里，它仍然明显更好（70% 的查询）。
    - 在近似平面的场景里，它会添乱（只有 30% 的查询更好）。
- **小载体比 DepthSplat-JEPA 更适合做远处补全。**
    - 选择之后，两个约 6.4 万参数的小载体（GA、G1）都通过了。
    - 两个 DepthSplat-JEPA 都没有通过：它们在远处视角上的覆盖与精度都不够。
- **局限：** 有 FARH 的场景只有 53 个；主检验勉强通过（CI 下界 +0.006）；扫描与 SELECTOR-V1 相同。
