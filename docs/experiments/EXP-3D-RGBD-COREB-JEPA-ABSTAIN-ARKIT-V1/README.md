## 解读

- **为什么 PAIR 比 Core B 好：**
    - Core B 用几何平均把 TTT 拉向 R7，换来了一致性，但牺牲了均值：TTT 单独的均值一直比 Core B 低。
    - PAIR 把集成伙伴从 R7 换成 JN 的前馈。JN 在可靠的像素上给出自己的深度，在不可靠的像素上就是 R7。
    - 所以 PAIR 的均值回到 TTT 单独的水平，同时对 R7 仍有 86% 的一致性。
- **为什么说贡献是边际性的：**
    - PAIR 与 TTT 单独打平（S6）。
    - 如果只看均值，直接用 TTT 单独就能得到同样的结果。
    - PAIR 的价值只在于一致性的折中：比 TTT 单独更稳，比 Core B 略不稳。
- **MASK 无效：** 在 JN 认为不可靠的像素上让 TTT 也退回 R7，反而变差（SYSTEM3 0.1584）。TTT 在这些像素上比 R7 更准。也就是说，JN 的弃权信息对前馈有用，对 TTT 之后的状态没有用。
- **对逆向 JEPA 的总体结论：** 它在真实数据上给出了一个小而稳健的前馈改进（有选择的弃权）。但对用 TTT 的完整系统，最多只是边际的帮助。
