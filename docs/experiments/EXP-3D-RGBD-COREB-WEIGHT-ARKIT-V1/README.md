# EXP-3D-RGBD-COREB-WEIGHT-ARKIT-V1：Core B 中 TTT 与 R7 的集成权重

**结论：WEIGHT_IMPROVES_CORE_B_PARTIAL（SYSTEM3 与 VAL 都是 PARTIAL）。把权重从 0.5 调到 0.9，均值稳定地降低约 1.6%，但逐场景只有约 65% 变好，对 R7 的一致性也从 93% 降到 81%。**

- **开发集选择（ARKIT_SYSTEM + ARKIT_SYSTEM2）：** 误差随 w 增大而降低，到 0.9 最低（0.1496；w = 1.0 为 0.1497），w* = 0.9。比 R7 好的场景数则从 141/160 降到 133/160。
- **P1（SYSTEM3）：** CORE_B − GEO_0.9 = +0.0025 [+0.0015, +0.0036]，106/0/54，PARTIAL；0.1569 → 0.1544。
- **P2（VAL）：** +0.0019 [+0.0006, +0.0034]，52/0/28，PARTIAL；0.1161 → 0.1142。
- **两个 PARTIAL 都只差逐场景一致性。** CI 都不含 0。
- **GEO_0.9 与 TTT 单独几乎相同：** SYSTEM3 上都是 0.1544；TTT 单独对 Core B 为 +0.0025，98/0/62（S4）。
- **对无模型方法：** GEO_0.9 为 130/0/30（SUPPORTED），TTT 单独为 126/0/34，Core B 为 149/0/11。
- **结论：** 均值与一致性之间是一条平滑的取舍，没有同时优于两端的权重。
    - 要最一致，用 Core B（w = 0.5）；
    - 要最低均值，用 TTT 单独或 w = 0.9，两者几乎相同。
