# EXP-3D-RGBD-DEPTHSPLAT-ALPHA-THRESHOLD-ARKIT-V1：只调高读出阈值，能否得到逆向 JEPA 的前馈改进，能否改进 Core B

**结论：JEPA_BEYOND_THRESHOLD_PARTIAL（VAL 上 SUPPORTED），THRESHOLD_CORE_B_NOT_ESTABLISHED。全局调高阈值不能复制逆向 JEPA 的改进。**

- **开发集曲线：** 在 ARKIT_SYSTEM + ARKIT_SYSTEM2（160 个扫描）上，发布权重的读出随阈值升高单调变差。
    - τ 从 0.5 升到 0.95 时，前馈的 ALL AbsRel 从 0.1549 升到 0.1569，覆盖率从 0.69 降到 0.46。
    - TTT 与 Core B 也同样单调变差。
    - 按预注册规则，τ_C* = τ_T* = 0.5，即原来的阈值就是最优的。
- **JN 的弃权是有选择的：**
    - 覆盖率相近时，发布权重（τ = 0.9，覆盖率 0.54）比 τ = 0.5 时更差，而 JN（覆盖率约 0.53）更好。
    - JN 学到的是"哪些像素不可靠"，而不是"整体少覆盖一些"。可以理解为它学会了用不透明度表示可靠性；这是解释，没有单独检验。
- **P1（SYSTEM3）：** 最优阈值下的发布权重仍比 JNS 差。+0.0041 [+0.0010, +0.0080]，110/0/50，PARTIAL；因为 τ_C* = 0.5，结果与 NF 相同。
- **S3（VAL）：** +0.0041 [+0.0012, +0.0070]，61/0/19，SUPPORTED。三项 V2 检查全部通过。
- **P2：** Core B 的最优阈值仍是 0.5，不需要改变。
- **结论：**
    - 只奖励精度的逆向 JEPA 学到了有选择的弃权，这是全局阈值做不到的。
    - 它对前馈状态的改进小（约 2.5%），但真实。

## 解读

- **"逆向 JEPA 的改进只是弃权"这一解释被排除了一半。**
    - 改进确实伴随覆盖率下降，但简单的全局弃权只会让结果变差。
    - JN 的价值在于弃权的位置：它在自己不可靠的像素上降低不透明度，把这些像素交给 R7。
- **Core B 的读出阈值不需要调整。** 在真实数据上，原来在 Hypersim 上定的 0.5 仍是最优。
- **下一步可以检验的组合：** 把 JN 学到的有选择弃权用到 Core B 里。例如，TTT 读出在 JN 认为不可靠的像素上也退回 R7，或者把 JN 的前馈与 Core B 集成。如果成立，逆向 JEPA 就能通过弃权改进完整系统。
