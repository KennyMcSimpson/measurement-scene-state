**结论：OVERLAP_JEPA_PARTIAL，OVERLAP_TRAINING_NOT_ESTABLISHED。**

- **在有重叠的新查询上，平均改善明显，但不一致（O1，PARTIAL）。**
    - 查询改为与上下文部分重叠的第 6、7 帧后，真实数据训练的逆向 JEPA 在 FAR 上平均明显好于调和插值：AbsRel 从 0.452 降到 0.341，约 −24%。

- **其他结论：**
    - 真实数据训练比合成数据训练好：Hypersim 训练的 J 是 0.407，对比调和插值不成立。

- **与 JEPA-ARKIT-V1 合起来看：**
    - 在重叠较多的近处视角（第 6、7 帧）上，学到的补全平均能带来约 1/4 的误差下降。
    - 在重叠很少的远处视角（第 14、15 帧中有命中的查询）上，它与调和插值打平。
    - 两种情况都过不了一致性门槛。

## 解读

- **学到的补全在真实数据上"平均有效、逐场景不稳"。**
    - 在部分可见的视角上，三种学到的补全都把 FAR 误差从 0.45 降到约 0.34：ARKit 训练的 JO、JA，以及 Hypersim 训练的小载体 G1N。
    - 但改善集中在一部分场景，中位场景几乎不变。这与 Hypersim 上旧载体（V17、V18）的情形一样：均值改善，约 2/3 的场景变好，过不了一致性门槛。
- **训练数据的作用：**
    - 用真实数据训练，DepthSplat-JEPA 从 0.407（Hypersim 训练）提升到 0.34，这是真实数据训练的实际收益。
    - 但只追平了一个 6.4 万参数、在 Hypersim 上训练的小载体。
    - 只在有重叠的目标上训练，没有额外收益。
- **重叠决定了补全能做多少。** 与 JEPA-ARKIT-V1 合起来看：近处视角（第 6、7 帧）上学到的补全平均降约 1/4 的误差；远处视角（第 14、15 帧）即使有命中，也与调和插值打平；完全无重叠时，只能学到"室内大概多深"。
- **下一步应关注一致性而不是均值。** 例如：
    - 弃权：只在模型有把握的像素上使用学到的补全；
    - 与调和插值集成：HJO 已经把一致性从 54% 提到 65%；
    - 弄清哪些场景会变差。

## 事后探索：一致性门控（探索性，样本内）

`exploratory_posthoc/gating_explore.*` 在同一批封存和真值上（FARH，147 个场景）比较了几种组合，所有组合在不满足条件的像素上都回退到 H3：

| 变体 | FARH AbsRel | 采用学习预测的像素比例 | H3 − X | 好/平/差 |
| --- | ---: | ---: | ---: | --- |
| JO（预注册读出） | 0.341 | 0.80 | +0.110 | 80/0/67 |
| HJO（与调和插值平均） | 0.374 | 0.80 | +0.078 | 95/0/52 |
| HJOG（H3、JO、G1N 三者平均） | 0.329 | 0.96 | +0.123 | 90/0/57 |
| JO 与 G1N 平均 | 0.301 | 0.97 | +0.150 | 79/0/68 |
| JO 种子一致（相对极差 ≤ 0.10） | 0.369 | 0.57 | +0.083 | 78/1/68 |
| JO 与 G1N 一致（相对差 ≤ 0.20） | 0.408 | 0.35 | +0.043 | 78/2/67 |

- **门控没有提高一致性。** 不论按种子一致性还是按两种独立模型一致性筛选像素，变好的场景都在 50–55% 之间。不一致不是像素级的不确定，而是场景级的：约 45% 的场景里，任何学到的补全都不如调和插值。
- **两种独立模型取平均最有效，但只体现在均值上。** JO 与 G1N 取平均把均值降到 0.301（约 −33%），但一致性不变。
- 以上是样本内的探索，没有用于任何预注册判定。
