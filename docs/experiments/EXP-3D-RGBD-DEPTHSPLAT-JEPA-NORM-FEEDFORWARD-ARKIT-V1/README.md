# EXP-3D-RGBD-DEPTHSPLAT-JEPA-NORM-FEEDFORWARD-ARKIT-V1：只奖励精度的逆向 JEPA 能否改进前馈状态（预注册复现）

**结论：JN1_FEEDFORWARD_PARTIAL，RECIPE_FEEDFORWARD_PARTIAL。改进在全新扫描和新种子上都复现了，大小与原来一致，但逐场景不够一致。**

- **P1（同一个模型 JN1）：** 160 个全新扫描上，JN1 的 7 帧前馈状态仍比发布权重好。
    - ALL AbsRel 为 0.1572 对 0.1608，+0.0036 [+0.0004, +0.0076]，好/平/差 109/0/51，PARTIAL。
    - 均值与 ARKIT_VAL 上完全相同（+0.0036），CI 不含 0。但只有 68% 的场景变好，没有达到 V2 gate 的 75%。
- **P2（配方，3 个种子平均）：** +0.0041 [+0.0010, +0.0080]，110/0/50，PARTIAL。三个种子分别为 +0.0036、+0.0045、+0.0042，CI 都不含 0（S8、S9）。
- **好处都在 NEAR7：** JN1 从 0.0763 降到 0.0717（−6%，S4，110/0/50）；FAR7 没有变化（S5）。
- **与无模型方法比较：** JN 的前馈胜过 R7（+0.0058，94/0/66，PARTIAL）；发布权重的前馈与 R7 打平（+0.0022，79/0/81）。
- **7 帧布局的 JK1 没有改进（S7）。**
- **结论：**
    - 只奖励精度的逆向 JEPA 训练对前馈状态有真实但很小的改进，约 2.5%。
    - 它在两个独立队列（ARKIT_VAL、ARKIT_SYSTEM3）和三个种子上，方向与大小都一致，但逐场景只有约 2/3 变好。
    - 这是本项目中逆向 JEPA 在真实数据上第一个可复现的正面效应。
    - 做 TTT 之后它没有优势（见 OBJECTIVE-TTT 的 P1）。

## 解读

- **这个改进是配方的稳定性质，不是 JN1 的偶然。** 两个独立队列上 JN1 的均值改进都是 +0.0036，新训练的两个种子也一样（+0.0045、+0.0042）。
- **机理与弃权一致。**
    - 训练后覆盖率从 0.72 降到约 0.53，好处全在 NEAR7。
    - 在那些模型自己不可靠、R7 更准的地方，模型交给了 R7。
    - 但约 1/3 的场景变差，说明弃权的位置并不总是对的。
- **实用意义有限。**
    - 不能运行 TTT 时，JN 的前馈比发布权重和 R7 都好，均值上接近 Core B。
    - 但 Core B 逐场景更好，而且一致得多：对 R7 是 149/11，JN 前馈对 R7 是 96/64。
    - 有时间做 TTT 的场景，仍应使用 Core B。
- **对逆向 JEPA 的总体结论：** 在 182 个真实训练扫描的规模下，只奖励精度的逆向 JEPA 能稳定地小幅改进前馈状态（PARTIAL），但不能改进 TTT。
