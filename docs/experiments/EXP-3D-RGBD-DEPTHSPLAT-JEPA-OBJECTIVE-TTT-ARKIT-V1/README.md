# EXP-3D-RGBD-DEPTHSPLAT-JEPA-OBJECTIVE-TTT-ARKIT-V1：只奖励精度的逆向 JEPA 能否改进 TTT

**结论：JN_TTT_NOT_ESTABLISHED，JK_HARMS_TTT。**

- **P1：** 训练目标改为只奖励已覆盖像素的精度后（JN1），JC 的损害消失了，但 TTT 结果只是与发布权重打平。ALL AbsRel 为 0.1149 对 0.1141，−0.0008 [−0.0032, +0.0016]，30/0/50，NOT_ESTABLISHED。
- **P2：** 再按 TTT 评估的布局训练，TTT 结果反而变差。JK1 用上下文 3 帧加流式帧 4 帧建状态，目标为第 14、15 帧。结果为 0.1178，−0.0038 [−0.0069, −0.0006]，24/0/56，HARMFUL。
- **新现象：只奖励精度的目标让模型学会"弃权"。**
    - 7 帧前馈状态的覆盖率从 0.73（发布权重）降到 0.55（JN）和 0.26（JK）。F7 读出在未覆盖处退回 R7。
    - 结果，不做 TTT 时 JN 的前馈状态比发布权重好：0.1172 对 0.1208，+0.0036 [+0.0009, +0.0062]，60/0/20，SUPPORTED（次要分析 S3）。好处全在 NEAR7：0.0718 对 0.0764，R7 为 0.0757。
    - TTT 把这点差距抹平了。发布权重经 TTT 从 0.1208 降到 0.1141，JN 只从 0.1172 降到 0.1149，JK 几乎没变（0.1182 → 0.1178）。
- **结论：**
    - 在 182 个 ARKit 训练扫描上，四种逆向 JEPA 预训练设置（JA、JC、JN、JK）都没有给 TTT 更好的起点；最好的 JN 只与发布权重打平。
    - Core B 的实用配置不变。逆向 JEPA → TTT 这条线到此结束。
    - 唯一的正面结果是 S3：不做 TTT 时，只奖励精度的逆向 JEPA 改进了前馈状态。它只有一个种子，又是次要分析，正在全新扫描上用 3 个种子做预注册复现（EXP-3D-RGBD-DEPTHSPLAT-JEPA-NORM-FEEDFORWARD-ARKIT-V1）。

## 解读

- **训练目标确实是 JC 损害的来源。** 只换目标后，TTT 结果从 0.121 回到 0.115，与发布权重打平；前馈状态从 0.173 变为 0.117。对 JC 的改进（S1）为 +0.0062，52/0/28，CI 下限略低于 0。
- **只奖励精度的目标会让模型主动弃权。**
    - 未覆盖的像素不产生损失，而去掉放错位置的高斯能降低已覆盖像素的误差，所以不透明度整体下降、覆盖率降低。
    - 7 帧布局下更极端，前馈覆盖率只有 0.26。
    - 这一机理是推测，没有单独检验。
- **弃权对前馈有用，对 TTT 没用。**
    - 不做 TTT 时，JN 把不可靠的区域交给 R7，所以比发布权重更准（S3，60/0/20）。
    - TTT 用 7 帧测量深度重新优化高斯，本身就会修正这些区域。发布权重经 TTT 后，NEAR7 达到 0.0685，好于 JN 的 0.0694 和 JK 的 0.0728。
    - 弃权留下的低不透明度起点，100 步 TTT 也拉不回同样的精度：JN、JK 的 TTT 覆盖率为 0.70、0.64，发布权重为 0.72。
- **对 Core B 的含义：**
    - 实用配置不变，仍是"发布权重（上限 0.1）+ TTT + 与 7 帧重投影取几何平均"。
    - 逆向 JEPA → TTT 这条线到此结束：四种设置中最好的只是打平。
- **值得复现的副产品：**
    - 只奖励精度的逆向 JEPA 改进了不做 TTT 的前馈状态。如果复现成立，它可用于不能运行 TTT 的场景（TTT 每个查询约 50 秒）。
    - 复现实验 NF 已于 2026-10-09 19:23 锁定，早于 FULL-SYSTEM-V3 读取同一批扫描的任何真值。
