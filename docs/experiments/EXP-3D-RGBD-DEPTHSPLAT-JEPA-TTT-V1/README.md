# EXP-3D-RGBD-DEPTHSPLAT-JEPA-TTT-V1：以 DepthSplat 为基座检验逆向 JEPA 与 TTT

**结论：两者都作为机制成立；相对无模型方法的优势都只达到 PARTIAL，场景一致性不够。逆向 JEPA 的补全水平与旧项目的 G1 载体相当，没有超过它。**

- **Core A（逆向 JEPA）：A_PARTIAL。**
    - 训练前，DepthSplat 的高斯几乎碰不到上下文没看到的区域（FAR 覆盖率 2%）。用"预测其他视角的深度与 RGB"训练整个编码器之后，状态覆盖了 68% 的 FAR，FAR AbsRel 从 0.425 降到 0.360。
    - 相对调和补全（0.429）平均好 0.069 [+0.014, +0.138]，但只有 45/77 个场景变好。
    - 相对旧项目的 G1 载体，增量只有 +0.015，不显著。
- **Core B（TTT）：B_MECHANISM_ONLY。**
    - 新到达 4 帧 RGB-D 后，在 DepthSplat 由 7 帧生成的高斯状态上做 100 步测试时优化。查询深度 ALL AbsRel 从 0.148（只缓存）降到 0.118，73/78 个场景变好（SUPPORTED）。
    - 平均也好于同样 7 帧的无模型重投影（0.175，+0.057），但只有 54/78 个场景变好（PARTIAL），中位数只好 0.005。
    - 收益全部来自已有测量的区域，对 7 帧都没看到的区域没有作用。

## 设计（简述）

- **状态构建器：** 所有构建器都在有效像素处注入测得深度。
    - ZS：发布权重，高斯尺度上限 0.1。
    - ZS3：发布权重，上限 3.0。
    - J1–J3：逆向 JEPA。
        - 从发布权重出发，种子 20261008–10，各 4000 步，lr 5e-6，ViT 5e-7。
        - 数据为 TRAIN72 加 SEG-V1，共 312 条记录。
        - 每步把 3 帧上下文的状态渲染到 2 个其他帧。损失是原始渲染深度的相对 L1 加 0.5 × RGB L1；上限 3.0。
        - 每个种子用时 1.65 h，显存 6.2 GB。
- **臂：**
    - CTX：3 帧上下文；
    - CACHE：3 帧上下文加 4 帧流帧，作为 7 视角前馈；
    - TTT：在 CACHE 上做 100 步 Adam，只用于 ZS，步长 m = 1，在 DEV 上选出。
    - 无模型对照：
        - REPROJ_HARMONIC（3 帧 1 像素 z-buffer 加调和补洞）；
        - REPROJ7_HARMONIC（7 帧）；
        - G1：旧项目最强载体，3 个种子；FAR_G1 = NEAR 用调和补全，FAR 用 G1。
- **读出：** DepthSplat 深度 = (depth_z / α) / cos，只在 α ≥ 0.5 处使用。
    - `_F` / `_F7`：其余像素回退到 REPROJ_HARMONIC / REPROJ7_HARMONIC。
    - `_G1`：NEAR 用调和补全；FAR 中 α ≥ 0.5 处用 DepthSplat，其余用 G1。
    - `_H7`：NEAR7 用 REPROJ7_HARMONIC，其余像素同 `_F7`。
- **区域：**
    - NEAR：距 3 帧重投影命中 8 像素以内。
    - FAR：其余有效像素。
    - NEAR7 / FAR7：用 7 帧计算的同样划分。

## 解读

- **逆向 JEPA：**
    - 在 DepthSplat 上，"预测其他视角"的训练确实改变了状态做什么。像素对齐的高斯原本只能停在上下文像素的射线上，训练后学会伸进未观测区域，而且在那里比调和插值准。这一点在三个种子上非常一致。
    - 但它的补全能力与旧项目的 G1 载体处在同一水平。G1 只有约 6.4 万参数，DepthSplat 有 1.2 亿。所以"更强的基座"没有把 learned completion 推过旧的天花板。
    - 场景层面仍然有约 40% 的场景比调和插值差，与旧项目的结论（PARTIAL、ND）一致。
- **TTT：**
    - 在 DepthSplat 状态上，测试时梯度写入的机制效应比旧载体更清楚：+0.030，73/78；旧载体 V8 为 +0.021。
    - 它让状态在平均上超过了无模型的 7 帧重投影。但这主要来自 1 像素 z-buffer 在遮挡处的失效，而不是新的几何信息。中位数场景只好 0.005。
    - 对没看到的区域（FAR7）毫无作用。
- **仍是最大的收益：** 把新帧本身缓存进来（+0.093）和多测几帧（+0.087）。
- **一个直接的后续问题：** TTT 的这点优势究竟来自学到的基座，还是只来自"高斯表示加测试时优化"？由 EXP-3D-RGBD-DEPTHSPLAT-TTT-ABLATION-V1（无网络高斯加同样的 TTT）检验。
