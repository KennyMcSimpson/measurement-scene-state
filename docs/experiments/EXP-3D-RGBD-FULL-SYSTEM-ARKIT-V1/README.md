## 解读

- **Core B 是稳健的。** 三个独立的评估队列（合成的 EVAL34、真实的 VAL80、真实的 SYSTEM80）都给出了 71/9 到 71/12 的结果：TTT 写入学到的状态，再与 7 帧重投影集成，稳定胜过无模型方法。但真实数据上的绝对增益很小（ALL 从 0.152 降到 0.148）。
- **只看 3 个上下文帧的补全，不能为 7 帧系统增加价值。** 在流式设置里，FAR7 区域周围有紧挨查询的帧作为插值边界。远处的 3 个上下文帧提供的补全，比不上这些近处边界的插值。
- **下一步如果要整合两条线，补全模型需要吃进全部 7 帧。** 小载体在训练时本来就支持 3–7 个视角，可以直接这样评估。选择规则（深度范围阈值）也需要在 7 帧设置下重新标定。

## 事后探索：7 帧载体（探索性，样本内）

上面的失败原因是：补全只看到了 3 个上下文帧。小载体训练时就支持 3–7 个视角，所以 `exploratory_posthoc/eval_carrier_7view.py` 用全部 7 帧（上下文 + 流式帧）为 G1、GA 建状态并封存，`full7_explore.*` 在同一批数据上比较了 9 种接入方式：

| FAR7 中替换 R7 的方式 | FAR7 AbsRel | 接进 Core B 后的 ALL 变化（CORE_B − X） | 好/平/差 |
| --- | ---: | --- | --- |
| R7（Core B 现状） | 0.270 | — | — |
| 3 帧 GA | 0.339 | — | — |
| 7 帧 GA，所有 episode | 0.295 | +0.0039 | 28/23/29 |
| sqrt(R7 × 7 帧 GA)，所有 episode | 0.271 | +0.0053 [+0.0002, +0.0122] | 32/23/25 |
| sqrt(R7 × 7 帧 GA)，只在 S ≥ 1.2 的 episode | — | +0.0025 [+0.0005, +0.0049] | 20/50/10 |

- **7 帧载体比 3 帧好得多，但单独使用仍不如 R7。**
- **把它与 R7 取几何平均后接入 Core B，效果最好。** 这相当于把 R7、GA、TTT 三者集成，在样本内带来小而一致的改进。按深度范围选择后，最一致的组合让 ALL 从 0.1475 降到 0.1451。
- **这是从 9 种变体里挑出来的，需要在全新数据上确认。** 确认实验见 EXP-3D-RGBD-FULL-SYSTEM-ARKIT-V2。
