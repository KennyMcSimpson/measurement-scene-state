# EXP-3D-RGBD-FULL-SYSTEM-ARKIT-V3：Hypersim 小载体 G1 的选择性集成能否改进 Core B（独立检验）

**结论：G1_SYSTEM_IMPROVEMENT_NOT_ESTABLISHED，G1_SYSTEM_BEATS_MODEL_FREE。Core B 第五次在全新扫描上复现（149/0/11）。**

- **主检验 P1（不成立）：** V2 次要分析中成立的 G1 接法，在 160 个全新扫描上方向为正，但不显著。
    - 结果为 +0.0010 [−0.0003, +0.0025]，好/平/差 38/99/23；ALL 从 0.1569 降到 0.1559。
    - 99 个场景是平局，SYS_G1 与 CORE_B 完全相同：其中 84 个场景两个角色都未被选中；另外 15 个场景虽有角色被选中，但接法没有改变任何被计分像素的值。
- **FAR7 中有小而稳定的改进（S1，次要）：**
    - +0.0062 [+0.0010, +0.0118]，36/96/25，SUPPORTED；FAR7 从 0.2983 降到 0.2921。
    - FAR7 只占有效像素的 22%，摊到 ALL 后不显著。
- **主检验 P2（成立）：** 完整系统稳定胜过无模型方法，+0.0071 [+0.0047, +0.0097]，139/0/21。这主要来自 Core B 本身。
- **Core B 第五次复现（S2）：** +0.0061 [+0.0042, +0.0082]，149/0/11，是五次中最一致的一次。TTT 本身的增益（S3）为 +0.0064，130/0/30。
- **三次检验合起来看：**
    - G1 接法在 V1（事后计算）为 +0.0002，V2（次要分析）为 +0.0042，V3（预注册主检验，160 个扫描）为 +0.0010。
    - 即使效应存在，也只有约 0.5%，本研究的样本量不足以确认。
    - 完整系统的实用结论仍是 Core B。

## 解读

- **Core B 是这条研究线最稳健的结果。**
    - 它已在五个独立队列上复现：一个合成队列（Hypersim EVAL34），四个真实队列（ARKit VAL80、SYSTEM、SYSTEM2、SYSTEM3）。
    - V3 是其中最大的一个（160 个扫描），一致性也最高，93% 的场景变好。
    - 真实数据上的绝对增益约 4%（0.163 → 0.157）。
- **补全接入 Core B 的价值没有确立。**
    - G1 接法在 FAR7 内有小的稳定改进（S1），但对整体只有约 0.5% 的贡献。三次检验中，它只有一次（次要分析）达到显著。
    - GA 接法三次都不成立。
    - 两种 7 帧载体单独用在 FAR7 时都不如 R7（S6、S7）；它们只有与 R7 取几何平均、并且只用在被选中的 episode 时才略有帮助。
- **均值与一致性的取舍。** TTT 单独（ZS_TTT_F7）的均值在 V2、V3 上都低于 Core B（V3：0.1544 对 0.1569）。但在以往的复现中，TTT 单独对 R7 的一致性较低（ARKIT_VAL 上 62/18）。Core B 用几何平均换来了一致性。
