# EXP-3D-RGBD-RESOLUTION-V8：在 V7 出结果之前写定的计划

起草：Claude，2026-09-29。写于 V7 的任何 DEV 指标生成或被查看之前（V7 当时正在训练第 2 个 seed）。本文件只记录后续两步的选择规则，不是正式协议；正式协议在 V7 完成之后另行冻结。

## 1. V7 之后先走哪一步

- **V7 为分支 A：** 下一步是在 FRESH-V2 上对 V7 C1 做资格验证（原样使用 V7 已封存的 checkpoint 选择）。V8 推迟到资格验证之后。
- **V7 为分支 B 或 C：** 下一步是 V8（分辨率）。FRESH-V2 保持封存。

## 2. V8 的基础 bounds 规则

- 如果 V7 的 BOUNDS_GAIN 点估计 >0，V8 用 V7 C1 的规则（测得上下文深度外包盒，不裁剪）。
- 否则用冻结规则。
- 不参考 V7 的其他任何结果。

## 3. V8 设计

- **单因素：** 体素网格分辨率。
  - C0：16³，基线，复现 V7 中对应规则的变体；
  - C1：32³，PRIMARY_METHOD；
  - C2：24³，次要，只作剂量-反应描述。
- **配方：** 冻结的 V5 C1 模型与 loss，TRAIN72，6000 步，同 seed 初始化。每个体素都是稠密证据候选。
- **已核实：** 三种网格的 5150 个共享参数及其按 seed 的抽取完全相同，参数哈希一致。
- **需要推广的三处冻结 16³ 限制**（写在新模块里，原模块不改）：
  - 深度似然的尺度 s 按变体自己的体素边长计算，与 V5 的定义一致；
  - 状态构建接受 g³ 个稠密候选；
  - 冻结的 V2 loss 接受 g³ 状态，但表面监督带宽仍保持冻结的 16 格间距，使 loss 本身不变。
- **CPU 耗时**（工程基准，仅用 TRAIN）：每步 16³ 为 0.109 秒，24³ 为 0.159 秒，32³ 为 0.273 秒。
- **主对比与分支：**
  - 主对比：RESOLUTION_GAIN = AbsRel(C0) − AbsRel(C1)，使用冻结的 V2 gate。
  - 分支 A：RESOLUTION_STATUS=SUPPORTED，且 C1 在全部 DEV 场景上显著优于 AbsRel 最优常数。
  - 分支 B：RESOLUTION_GAIN 的 CI 下界 >0，或 C1 在全部场景或排除 NO_HIT 后的场景上优于常数，但不满足 A。
  - 分支 C：其余情况。

## 4. FRESH-V2

- **数据：** EXP-3D-RGBD-FRESH-V2-DATA 已准备好 17 个独立场景，没有做过任何模型前向。
- **使用规则：** 只给第一个达到分支 A 的 DEV 方法做一次资格验证。
- **资格 gate：**
  - 主对比复现；
  - 场景专属性；
  - 多视角融合；
  - C1 在全部 FRESH-V2 场景上 RAW AbsRel 显著优于 AbsRel 最优常数。
