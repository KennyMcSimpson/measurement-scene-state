# EXP-3D-RGBD-TTT-ENSEMBLE-V1：TTT 后的状态与无模型重投影取平均

**结论：T1 = TTT_ENSEMBLE_CONSISTENT，T2 = TTT_NEEDED。**

- **T1：** 新帧到达后，把"测试时优化过的 DepthSplat 状态"与"同样 7 帧的无模型重投影"逐像素取几何平均，在 EVAL34（83 个场景）上稳定胜过无模型重投影：+0.029 [+0.015, +0.047]，71/83 个场景更好，V2 gate 全部通过。
- **T2：** TTT 是必要的。把 TTT 换成"只缓存新帧"的状态再做同样的平均，83 个场景中有 80 个更差（+0.019，SUPPORTED）。
- **复现 V1 的 Core B：** TTT 相对只缓存 +0.032（79/4，SUPPORTED）。TTT 单独相对无模型重投影 +0.040，但只有 59/83，PARTIAL；正是这个一致性问题，被集成解决了。

## 解读

- **均值与一致性的取舍：**
    - TTT 单独的均值最好（0.134），但只有 71% 的场景比无模型重投影好。
    - 与无模型重投影取几何平均后，均值变差一点（S8：−0.011），换来 86% 的场景一致更好。
    - 这与 EXP-3D-RGBD-COMPLETION-ENSEMBLE-V1 在补全上看到的规律相同：学到的状态与测量驱动的结果取平均，压住了状态出错的场景。
- **TTT 不可缺少：** 只缓存新帧的状态多数场景比无模型重投影差（S5：30/53），取平均后仍然多数更差（S4：34/49）。只有经过测试时优化的状态，才值得和测量结果平均。
- **收益仍在已测区域：** NEAR7 +0.030，FAR7 只有 +0.001。
- **对 Core B 的含义：** "新帧到达后对学到的状态做梯度写入"终于在样本外队列上显示出稳定的实用价值。但用法是：把写入后的状态与测量驱动的重投影结合，而不是单独使用。
