# EXP-3D-RGBD-WIDTH-DATA-V15

宽度 × 数据的检验：在 V14 C1 的配方上（V11 C1 配方，TRAIN72 + TRAIN-EXT 共 127 个训练场景），把 carrier 宽度从 32 加到 64（250,542 个参数）。计划在任何 V15 训练之前写定；C0（宽度 32）必须与 V14 C1 逐位相同。主评价在 EVAL-V3 与 EVAL-V4 的合并队列（83 个场景）上进行；EVAL-FAR 只作描述。所有预测在读取 query 深度之前封存。全程 CPU。

FAR 为离上下文深度重投影命中点超过 8 像素的像素（占 20.7%）；HFILL8 在其余像素用调和插值补洞，在 FAR 用 carrier；AHFILL8 另把不透明度 < 0.5 的 FAR 像素也交给调和插值（V13）。
