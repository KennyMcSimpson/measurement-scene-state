# 二维观测反馈与动态写入：首轮小实验

日期：2026-09-21。状态：旧 3D 数据清理完成，二维数据及权重下载完成，首轮真实数据实验运行、修正和独立核验完成。

**当前结论：已经找到需要解决的问题，但还没有验证出一个有效的完整方法。模型更会还原颜色，不等于更会认出同一个对象。仅用 RGB 重建误差决定写入动作，目前没有可靠收益。**

本实验只检查一条最简反馈通道及两种写入动作。它不是完整的逆向 JEPA，也不是自然视频上的持续动态 TTT；不能用它直接宣判两个核心创新成立或失败。

## 这次究竟测了什么

把同一视频的首帧作为参考，用冻结 DINOv2 特征寻找后续帧里最相似的位置，再把首帧对象标签传过去。我们观察修改后续帧的内部特征，是否使对象对应更准确。

全程只使用官方 train 的 60 段视频，按序列名 SHA256 排序固定划分：

| 用途 | 视频数 | 实际使用 |
|---|---:|---|
| 拟合 | 24 | 拟合 PCA 和 RGB 线性读出，不训练 DINOv2 |
| 发现与选择参数 | 12 | 从预设步长及固定动作路径中选择配置 |
| 独立验证 | 16 | 配置冻结后运行，共 32 个首帧到后续帧的图像对 |
| 保留 | 8 | 不提取特征、不评价 |
| 官方 val | 30 | 不参加此次实验 |

每段使用首帧，以及排序后帧数的 1/3、2/3 位置；合计提取 156 张图的特征。骨干输入是 224×224，输出是 16×16 个 patch 特征。PCA 将特征投影并白化到 64 维；RGB ridge 读出只在拟合集学习，此后冻结。

每张目标图有两份初值为零的私有快权重。A 修正各位置的特征通道，B 根据 3×3 邻域特征修正。用当前图像真实 RGB 与读出预测的差异，直接产生外积更新；没有测试时反向传播或 SGD。两步都可选 OFF、A、B、ALL，共 16 条路径。ALL 的两份增量都从同一个旧状态计算。

最简单的动态策略在每步试算四个候选，用另一组可见 patch 的 RGB 误差选动作。用于选择的 patch 不直接进入该步残差写入，但 DINO 已经看过全图，因此这里**不是未见像素预测，也不存在严格的空间信息隔离**。选择区域反复用于选动作，不能再把它当作独立验证集。

首帧标签和后续帧真值只用于下游传播与评价，不进入写入或无标签策略。源特征不更新，每张目标图的状态重置。本轮没有跨帧记忆、遮挡恢复或长期错误传播实验。

## 独立验证结果

指标是 **16×16 token 网格上的平均对象 IoU**，先对每段视频的两个目标取均值，再对视频平均。它不是官方 DAVIS J&F，不能拿下表直接与公开 VOS 排行榜比较。

| 方法 | 对象 IoU ↑ | 相对不写入，百分点 | RGB MSE ↓ |
|---|---:|---:|---:|
| 不写入 | 44.34% | 0 | 0.03022 |
| 固定 A→A | 44.26% | −0.08 | 0.01511 |
| 固定 B→B | 44.28% | −0.06 | 0.01532 |
| 固定 ALL→ALL | 44.20% | −0.14 | 0.01616 |
| 发现集选出的固定 OFF→ALL | 45.08% | +0.75 | 0.01770 |
| 按 RGB 误差动态选择 | 44.03% | −0.31 | 0.01250 |
| 每个图像对看答案选最佳恒定动作，仅诊断 | 44.70% | +0.36 | 0.02373 |
| 每个图像对看答案选最佳两步路径，仅诊断 | 45.51% | +1.18 | 0.02407 |

发现集选定步长为 5.0、固定路径为 OFF→ALL；验证时没有重新选参数。动态策略的步长沿用这个选择，未对动态策略单独调参。

按视频做 10,000 次配对 bootstrap，固定 OFF→ALL 相对不写入的差值区间约为 **[−0.46, +2.53] 个百分点**；动态策略约为 **[−1.38, +0.47] 个百分点**。样本少，区间较宽，目前无法声称稳定提升或确定的普遍退化。这是探索性描述，不是多重比较校正后的确证检验。

oracle 在本次候选集合内使用了任务答案挑选路径；包含 OFF，因此天然不会比 OFF 差。它只刻画有限搜索空间里的机会，不是可部署结果，更不是完整模型的性能上限。

## 这些数字说明什么

**第一，反馈确实能改动状态，但反馈目标和任务目标之间有落差。** 动态策略的平均 RGB MSE 比不写入低约 58.6%，而对象 IoU 没有提升。直白地说，它学会让内部特征更容易解释颜色，却未学会怎样改动才能更准确地对应对象。这支持继续研究“什么观测约束值得用于写入”，不支持直接加大 RGB 重建训练规模。

**第二，动作路径的机会有限，而且高度集中。** 最佳两步 oracle 比最佳恒定动作 oracle 高约 0.82 个百分点，但额外收益只出现在 32 个图像对中的两个。主要贡献来自 `scooter-board`，另一个是 `koala`。这还不足以证明普遍需要复杂动态控制器。

**第三，当前评价分辨率明显限制了判断。** 事后检查发现 `scooter-board` 的第二个目标帧，在 16×16 网格上只有一个前景 token。一个 token 的改变就可能带来很大的对象 IoU 跳动。保留全部视频时固定策略表面提升 0.75 个百分点；仅作为事后敏感性检查，去掉这段后其平均差值约为 −0.04 个百分点。主结果仍保留这段，不能为了好看而删样本。

动态策略平均改变约 4.00% 的最近邻位置，但只改变约 0.23% 的对象标签位置。这说明许多特征变化发生在同一对象内部；粗网格标签评价也容易出现大量平局。oracle 中选择 OFF 的次数包含平局时优先 OFF，不能解释成这些样本都必须禁止写入。

本轮写入规则本身也很简化：RGB 残差乘冻结 decoder 的转置再作标量归一化，并非 decoder 的精确逆，也不是完整双层结构的精确梯度。不能把该启发式规则的结果推广到所有观测驱动写入机制。

## 对两个核心创新的意义与下一步

倒着的 JEPA 在完整方案里应当要求：内部共享状态能够被真实观测检查，后续观测可揭示状态的错误。动态 TTT 决定什么时候改、改哪部分、何时保留旧状态。这次只触及“真实观测残差→私有写入→动作选择”这段接口，尚未构建共享状态、多观测一致性和未来观测检验。

**现在最值得保留的切口是：如何让观测反馈识别有用写入，并拒绝只改善当前重建、却损伤后续视觉任务的写入。** 这与两个核心的关系更直接，但仍需证据。

下一步应先在发现集做两件小事，再决定是否进入完整模型训练：

1. 提高网格分辨率或采用可靠的稠密读出，检查动作机会是否仍存在，避免被一两个 token 的变化主导结论。
2. 比较 RGB 残差与跨观测一致性、对应循环一致性等部署时可取得的信号，检查哪种信号能够预测写入后的任务变化；允许 OFF，明确错误写入的代价。

这些只是下一阶段建议，本轮没有偷偷更换反馈目标、重新调验证集参数或启动大训练。已经看过的 16 段不再适合当未来方案的最终独立验证依据；下一轮需明确新的开发与封存边界。官方 val 和 8 段保留视频仍未用于特征或任务评价。
